# Goofy Horror

A browser-based game. Real JavaScript, no build step.

## Running it

No install, no build. Open [`index.html`](index.html) in a browser, or serve
the folder with any static server, e.g.:

```
npx serve .
```

## Controls

Split-screen local 2-player. Player 1 (orange, left half) moves with `W`
`A` `S` `D`; Player 2 (green, right half) moves with the arrow keys.
`index.html` currently ships a bare canvas scaffold to prove the base
project and controls work — game structure, levels, and art direction are
still being designed.
